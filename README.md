# YYT Music 自定义音源

在歌一刀 / KMusic 的 设置 → 自定义源管理 中，选择「URL 导入」，粘贴下面任意一行链接即可。

- `flower.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/flower.js
- `grass.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/grass.js
- `huibq.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/huibq.js
- `ikun.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/ikun.js
- `juhe.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/juhe.js
- `liumingye-lx-dujia.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/liumingye-lx-dujia.js
- `lx.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/lx.js
- `sixyin.js`: https://raw.githubusercontent.com/fengyvle/yyt-music-sources/main/sixyin.js

> 这些音源兼容 [lx-music](https://github.com/lyswhut/lx-music-desktop) 格式。
